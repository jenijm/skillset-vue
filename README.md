# Hello from Vue

A basic Vue.js application that displays:

```text
Hello from Vue!
```

The project uses Vue 3 and Vite.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

Open the URL displayed in the terminal, normally:

```text
http://localhost:5173
```

The development server listens on all interfaces, so another reachable device can use the displayed Network URL.

## Create a production build

```bash
npm run build
```

The optimized application is generated in `dist/`.

## Preview the production build

```bash
npm run preview
```
